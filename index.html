Browser Testbed

A dependency-free static site that exercises as much of the web platform as a real site would: every input type, native and custom pickers, file and camera capture, every flavour of navigation, overlays, gestures, storage and rendering stress. Built to be pointed at a browser under development.

How to use it three built-in test hooks

  • Every interactive element carries a stable data-testid.
  • Event log (Alt+L, or the button in the header) shows every DOM event the browser produced — it survives page navigation, so multi-page flows stay traceable.
  • window.__testbed gives automation a handle: ids(), value(id), setValue(id, v), click(id), state(), events(), features().
  • Feature detection reports which APIs this browser supports.
